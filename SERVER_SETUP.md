# Настройка функциональности серверов

## Описание

Эта функциональность позволяет пользователям создавать собственные серверы (сообщества) в приложении Discord-clone.

## Компоненты

### Фронтенд

1. **Типы и интерфейсы** - `Frontend/src/features/servers/types.ts`
2. **API функции** - `Frontend/src/api/servers.ts`
3. **Компонент кнопки создания сервера** - `Frontend/src/components/CreateServerButton.tsx`
4. **Модальное окно создания сервера** - `Frontend/src/components/CreateServerModal.tsx`
5. **Стили** - `Frontend/src/components/CreateServerModal.css`

### Бэкенд

1. **Модели**:
   - `backend/src/models/Server.js`
   - `backend/src/models/Channel.js`
   - `backend/src/models/Member.js`

2. **Контроллер** - `backend/src/controllers/serversController.js`
3. **Маршруты** - `backend/src/routes/servers.routes.js`

## Установка и запуск

### 1. Запуск базы данных

Для работы серверов необходима PostgreSQL база данных. Запустите контейнеры с помощью:

```bash
./start-containers.bat
```

Или вручную:

```bash
docker-compose up -d
```

### 2. Настройка переменных окружения

Убедитесь, что файл `backend/.env` содержит правильные настройки подключения к базе данных:

```
DB_HOST=localhost
DB_PORT=5432
DB_NAME=discord_clone
DB_USER=postgres
DB_PASSWORD=password
```

### 3. Запуск бэкенда

```bash
cd backend
npm install
npm run dev
```

### 4. Запуск фронтенда

```bash
cd Frontend
npm install
npm run dev
```

## Использование

1. Откройте приложение в браузере
2. Войдите в систему или зарегистрируйтесь
3. Нажмите на кнопку "+" в нижней панели навигации
4. Заполните форму создания сервера:
   - Введите название сервера (2-100 символов)
   - (Опционально) Загрузите иконку (PNG, JPG, JPEG, GIF до 5MB)
   - Выберите шаблон сервера
   - Выберите регион
   - Установите уровень приватности
5. Нажмите "Создать"

## Тестирование

Для тестирования функциональности можно использовать тестовый скрипт:

```bash
node backend/test-servers.js
```

Этот скрипт создаст тестовый сервер в базе данных и проверит корректность работы моделей.

## API эндпоинты

- `POST /api/servers/create` - Создание нового сервера
- `GET /api/servers` - Получение списка серверов пользователя
- `GET /api/servers/:serverId` - Получение информации о сервере

## Обработка ошибок

Функциональность включает обработку следующих ошибок:

- Название сервера слишком короткое или длинное
- Сервер с таким названием уже существует
- Иконка слишком большого размера
- Неподдерживаемый формат файла иконки
- Ошибки сети и сервера

## Анимации и микро-взаимодействия

- Плавное открытие/закрытие модального окна
- Анимация кнопки создания при наведении и клике
- Индикатор загрузки при создании сервера
- Валидация в реальном времени
- Подсчет оставшихся символов в названии
